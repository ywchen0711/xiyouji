# 西遊記・八十一難 · Journey to the West

把《西遊記》一百回完整寫成的線性 RPG：從石猴出世到五聖成真，一難不少。

- **完整的故事**：五十二個章節，照著原著一回一回走。
  - **大鬧天宮**：石猴出世、拜師菩提祖師、龍宮借寶、大鬧地府、弼馬溫與齊天大聖、蟠桃會、二郎神、八卦爐、五行山。
  - **取經緣起**：魏徵斬龍、太宗遊地府、江流兒、水陸大會。
  - **西天取經**：雙叉嶺、兩界山、鷹愁澗、黑風山、高老莊、黃風嶺、流沙河、四聖試禪心、五莊觀、三打白骨精、寶象國、平頂山、烏雞國、紅孩兒、車遲國鬥法、通天河、金兜山、女兒國、琵琶洞、真假美猴王、三調芭蕉扇、祭賽國、荊棘嶺、小雷音寺、稀柿衕、朱紫國、盤絲洞、獅駝嶺、比丘國、無底洞、滅法國、隱霧山、鳳仙郡、玉華州、金平府、天竺國、寇員外、凌雲渡、通天河落水，一直到靈山取經、回到長安、五聖成真。
  - 七百多段文字與對白，多取自原著。
- **八十一難**：觀音菩薩的災難簿子，一難一難記下來，隨時可以從選單查看。
- **每一章**：先是故事；有時有城鎮可以住店、買東西、打聽消息；然後走過一張地圖，路上有妖怪、寶箱和遇見的人；盡頭是那一回的大妖怪。
- **戰鬥**：
  - 正面視角，妖怪畫在戰場上，師徒四人的視窗排在下面。
  - 每回合下令：攻擊、法術、道具、防禦，或是「總攻擊」讓大家自動打；然後依速度出手。
  - 孫悟空有身外身法、七十二變、定身法、火眼金睛、千鈞棒、毫毛萬猴。
  - 豬八戒有釘鈀亂築、天蓬水軍、震天鼾。
  - 沙悟淨有護師、八百流沙、九骷髏陣。
  - 唐僧有念佛、心經、緊箍咒（悟空頭疼，但力氣大增）、白龍馬、往生咒、金蟬法身。
- **大妖怪的法寶**：紫金紅葫蘆叫一聲名字就收人，芭蕉扇一搧就把人搧走（帶了定風丹就不怕），金剛琢套走所有兵器，人種袋把人裝走，紫金鈴噴火放煙。有些仗是故事要你輸的，像二郎神、鎮元大仙、紅孩兒的三昧真火：打到某一回合，故事就接下去了。
- **頭像**：老派戰略遊戲的像素頭像，每個人物在 32×40 的格子上一格一格畫出來，黑線描邊、平塗上色、左上打光。人物依臉色、冠帽、鬚髮與衣著組合；猴、豬、熊、虎、牛、獅、象、鵬、鹿、犀、蛇、龍等妖怪各有頭型、耳朵、角、口鼻、牙齒與花紋。唐僧戴毗盧帽，如來有螺髮和佛光，大聖頂著鳳翅紫金冠。
- **場景**：每一章的地圖照那個地方的樣子產生，同一種地形也不重複：
  - 野外有蜿蜒的道路、樹林與山崖（看得到崖壁和林下的樹幹）、溪流和木橋、池塘、寶箱所在的林間空地，路旁有土地廟、石碑、寶塔、農舍、水井。
  - 洞窟是自然生成的石室，有水潭、熔岩、鐘乳石、骷髏和蛛網。
  - 宮殿與寺院是一進一進的殿堂和庭院，紅毯、廊柱、花園和水池；天宮是雲海上的玉台，靠玉橋相連。
  - 各章有自己的花草、天氣和時辰：花果山的桃花、黑松林的陰暗、白虎嶺和隱霧山的霧、金兜山的雪、火焰山的熱浪、黃風嶺的風沙、毛穎山的夜色、通天河上的冰面和冰窟窿。
  - 戰鬥背景也是像素畫，跟著那一章的天色。
- **其他**：同伴與客將（劉伯欽、惠岸行者、昴日星官、哪吒、二郎神）、衣甲與飾物、城鎮商店與客棧，還有故事回顧，可以重看走過的章節。

操作：方向鍵 / WASD 移動，Enter / Z 決定、對話、開寶箱，Esc / X / C 選單與取消；對話中按 C 可以快轉。手機上有虛擬方向鍵和按鈕。

Pure HTML / Canvas / ES modules, no build step. All art and sound are generated in code. `node tools/test.mjs` checks the story data; `node tools/sim.mjs` reckons every boss fight at the level the story expects.
